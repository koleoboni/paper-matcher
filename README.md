## Features

- Venue binance / BTCUSDT
- Strategy mm
- Paper backtest, no live orders

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd paper-matcher
cargo build --release
./target/release/paper-matcher --help
```

## Tests
